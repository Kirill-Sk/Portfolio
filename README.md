# Портфолио: анализ данных

Проекты, выполненные для реальных заказчиков в рамках курса «Аналитик данных» (Яндекс Практикум, 2024). По обоим проектам есть рекомендательные письма от заказчиков.

| Название проекта | Заказчик и задача | Что сделано | Стек | 
| :---------------------- | :---------------------- | :---------------------- | :---------------------- |
| [Кадры здравоохранения Тверской области](Tver_SMU) | Тверской ГМУ: оценить укомплектованность медицинских организаций региона | Очистка и объединение данных о 1 413 работниках 113 организаций, поиск неявных дубликатов, расчёт удалённости от Твери, дашборд с картой | *python*, *pandas*, *matplotlib*, *seaborn*, *re*, *fuzzywuzzy*, *haversine*, *Yandex DataLens* |
| [Поведение жертвователей НКО](simple_things) | АНО «Простые вещи»: понять, как ведут себя жертвователи | RFM-сегментация 1 476 жертвователей, когортный анализ удержания и LTV, дашборд | _python_, _pandas_, _numpy_, _scipy_, _ydata_profiling_, _Yandex DataLens_ |
